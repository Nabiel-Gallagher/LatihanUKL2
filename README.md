# Program Ganjil / Genap

Program Java sederhana untuk menentukan apakah suatu bilangan merupakan bilangan ganjil atau bilangan genap.
---

## 💡 Fitur
- Menginput Angka (User Input)
  - Program meminta angka menggunakan `Scanner`
- Pengecekan Bilangan Ganjil / Genap
  - Logika if `angka % 2 == 0` untuk menentukan ganjil / genap
- Percabangan (if–else)
- Tampilan Rapi di Terminal
- Output Hasil Otomatis

---

## 🧮 Logika Program Singkat

  - **Input dari pengguna (Scanner)**
  - **Percabangan (if–else)**
  - **Operator aritmatika modulus (%)**
    
      `angka % 2 == 0	Bilangan Genap ✅ | (Bilangan Bisa Dibagi Dengan 2 =  Genap) `
      
      ` angka % 2 != 0	Bilangan Ganjil 🔹 | (Bilangan Tidak Bisa Dibagi Dengan 2 =  Ganjil) `

---

## 🖥️ Contoh Output 

```bash
====================================
PROGRAM CEK BILANGAN GANJIL / GENAP
====================================
Masukkan Angka:
7
-----------------------------------
7 adalah bilangan ganjil
===================================
```

```bash
====================================
PROGRAM CEK BILANGAN GANJIL / GENAP
====================================
Masukkan Angka:

===================================
```
